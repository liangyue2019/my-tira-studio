# 主页面（index）UI 布局

## 页面概述

主页面是游戏核心交互界面，根据游戏阶段（phase）呈现三种不同视图。默认状态为行动选择视图，结算和日终报告时切换为对应组件视图。

## 视图切换逻辑

```
phase === 'day_summary'  → DaySummaryView（日终报告）
phase === 'settlement'   → SettlementView（时段结算）
其他（action_select/event）→ 主页面（行动选择）
```

## 交互说明

- **行动卡片**：3 列网格，根据当前时段过滤可用行动，不可用行动置灰并显示原因
- **继续按钮**：结算后点击推进到下一时段，晚上结算后触发日终
- **重置游戏**：弹出确认弹窗，确认后重置所有数据
- **DialogModal / EventModal**：浮层遮罩，点击遮罩区域可关闭
