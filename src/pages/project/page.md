# 项目管理页面（project）UI 布局

## 页面概述

分为两个区域：进行中项目和可接受项目。项目卡片以难度颜色左边框标识，支持员工分配/移除操作。

## 项目卡片详情

### 进行中项目 (project-card)

- **左边框**：颜色按难度（1=绿, 2=蓝, 3=橙, 4=红, 5=紫）
- **项目名称**：白色加粗
- **客户/难度**：灰色 / 黄色星标
- **技能需求**：三列均分标签（编程/设计/沟通）
- **进度条**：蓝色填充 + 发光效果，右侧显示 `slotsSpent/totalSlots 时段`
- **截止日期**：黄色文字，显示剩余天数
- **已分配员工**：列表，每行显示员工名 + ✕ 移除按钮
- **分配空闲员工**：横向排列的蓝色边框按钮，点击分配
- **奖励**：顶部分隔线后三列显示 💰🏆✨

### 可接受项目 (available-card)

- 与进行中项目类似，额外包含：
  - `需要 N 个时段` 文字
  - **接受项目**按钮（蓝色边框，全宽）

## 交互说明

- **分配员工**：点击空闲员工按钮 → 双向同步（projectStore.assignEmployee + employeeStore.updateEmployee）
- **移除员工**：点击 ✕ → 双向同步（projectStore.removeEmployee + employeeStore.resetEmployeeStatus）
- **接受项目**：点击按钮 → addProject 并 showToast
- 难度颜色仅影响左边框，不影响卡片内容样式
